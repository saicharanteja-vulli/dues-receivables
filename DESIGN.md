# Dues visual direction

User requirement: every project must have a distinct visual identity. Do not duplicate the same layout, hero, card grid, type hierarchy or decorative motif across Orbit, Relay, Aegis, Proof and subsequent projects. A palette swap is insufficient.

Dues uses an editorial collection desk: permanent ink-blue navigation rail, off-white working surface, restrained coral highlights, large understated financial figures, serif editorial headings, ruled ledgers and linear aging charts. The sign-in screen uses a split cover composition. On phones the rail becomes a horizontal navigation strip.

Future project work should choose the domain-specific interaction model first, then a new composition, typography, density, navigation and motion system. Record that project's own direction before implementation. Avoid generic boxed statistic cards and repeating this Dues design as the next default.
